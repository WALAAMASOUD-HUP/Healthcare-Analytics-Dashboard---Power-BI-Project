Healthcare Analytics Dashboard – Power BI Project
This project presents an interactive Healthcare Analytics Dashboard built in Excel to analyze medical billing performance across procedures, departments, conditions, and locations.
The dashboard provides clear insights that support decision-making in healthcare operations and financial management.
________________________________________
🚀 Project Overview
The dashboard summarizes key healthcare financial metrics, including:
•	Total Billing Amount
•	Medication Cost
•	Treatment Cost
•	Insurance Coverage
•	Out-of-Pocket Payments
•	Room Charges
It also allows users to explore billing data using multiple interactive views.

📊 Dashboard Features
1. Billing Analysis by City & State
Visual map showing total billing amounts across major cities.
2. Billing by Procedure
Compares revenue generated from procedures such as:
X-Ray, CT Scan, MRI Scan, Ultrasound, and Blood Tests.
3. Billing by Department
Breakdown of billing contributions from departments including:
Cardiology, Orthopedics, General Surgery, Neurology, and Pediatrics.
4. Billing by Medical Condition (Type)
Displays total billing amounts by condition such as Hypertension, Asthma, Migraine, etc.
